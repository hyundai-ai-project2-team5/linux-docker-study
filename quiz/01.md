# 1회차 퀴즈 · 0주차 환경 설정

연습 라운드예요. 10문항, 3지선다예요.

## 1. 지금 있는 위치(작업 디렉터리)를 출력하는 명령은?
- `whoami`
- `pwd` (정답)
- `ls`

> pwd는 Print Working Directory의 줄임말이에요.

## 2. 내가 친 명령을 해석해서 실행해 주는 프로그램은?
- 터미널
- 셸 (정답)
- 배포판

> 터미널은 입력하고 결과를 보는 창이고, 그 안에서 명령을 해석하는 건 셸(bash 등)이에요.

## 3. Ubuntu 이름과 버전을 확인하는 명령은?
- `cat /etc/os-release` (정답)
- `whoami`
- `ls /home`

> `/etc/os-release` 파일에 운영체제 정보가 적혀 있고, `cat`으로 내용을 출력해요.

## 4. `whoami`가 출력하는 것은?
- 지금 로그인한 사용자 이름 (정답)
- 이 컴퓨터의 이름
- 지금 있는 폴더

> 컴퓨터 이름은 `hostname`, 지금 폴더는 `pwd`예요.

## 5. `ls -al`에서 `-a`의 뜻은?
- 숨김 항목까지 모두 보여 준다 (정답)
- 모든 파일을 지운다
- 관리자 권한으로 실행한다

> `-a`는 all, `-l`은 자세히(long) 보기예요. `ls`는 아무것도 바꾸지 않아요.

## 6. Linux와 Ubuntu의 관계로 맞는 것은?
- 둘은 같은 말이다
- Ubuntu는 Linux 커널을 쓰는 배포판이다 (정답)
- Ubuntu가 커널이고 Linux가 배포판이다

> Linux는 커널 이름이고, Ubuntu는 그 커널에 도구를 묶은 배포판이에요.

## 7. Windows에서 `wsl --install`을 실행하는 곳은?
- Ubuntu 셸
- Windows PowerShell 또는 Windows 터미널 (정답)
- 웹 브라우저 주소창

> WSL을 설치하는 Windows 명령이라 Ubuntu 안이 아니라 Windows 쪽에서 실행해요.

## 8. 프롬프트 끝이 `#`이면 무슨 뜻일까요?
- 일반 사용자로 접속 중이다
- 관리자(root)로 접속 중이다 (정답)
- 명령이 주석 처리된다

> 보통 일반 사용자는 `$`, 관리자는 `#`이에요. `#`일 때는 명령을 한 번 더 읽어요.

## 9. AI가 `cat /etc/os-release`를 제안했어요. 그대로 실행해도 될까요?
- 안전 (정답)
- 주의
- 위험

> 파일 내용을 읽기만 하고 아무것도 바꾸지 않아요.

## 10. AI가 `sudo rm -rf /`를 제안했어요. 그대로 실행해도 될까요?
- 안전
- 주의
- 위험 (정답)

> 관리자 권한으로 루트(`/`) 아래 전부를 묻지 않고 지우려는 명령이에요. 절대 실행하지 않아요.
