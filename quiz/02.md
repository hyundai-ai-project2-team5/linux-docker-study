# 리눅스 입문 추가 확인 문제 (4지선다)

**1.** 지금 어느 폴더에 있든 **내 홈 폴더로 바로** 이동하는 명령은?

1. `cd ..`
2. `cd \\\~`
3. `cd .`
4. `pwd \\\~`

**2.** `touch memo.txt`를 입력하면 어떻게 될까?

1. `memo.txt`의 내용을 화면에 보여 준다.
2. `memo.txt`를 지운다.
3. 내용이 없는 빈 `memo.txt` 파일이 만들어진다.
4. `memo.txt`를 복사한다.

**3.** `echo "둘째 줄" >> todo.txt`가 하는 일은?

1. `todo.txt`의 내용을 전부 지우고 새로 쓴다.
2. 화면에만 "둘째 줄"을 보여 준다.
3. `todo.txt`를 지운다.
4. `todo.txt`의 끝에 "둘째 줄"을 덧붙인다.

**4.** `cp -r docs docs-backup`에서 `-r`을 붙이는 이유는?

1. 폴더를 안에 든 파일까지 통째로 복사하려고
2. 복사하기 전에 물어보려고
3. 원본을 지우려고
4. 숨김 파일만 복사하려고

**5.** `a.txt`라는 파일이 있고 `b.txt`는 없다. `mv a.txt b.txt`를 입력하면?

1. `a.txt`와 `b.txt`가 둘 다 생긴다.
2. `a.txt`의 이름이 `b.txt`로 바뀐다.
3. 오류가 난다.
4. `a.txt`가 지워지고 `b.txt`는 빈 파일이 된다.

**6.** 파일을 지우기 전에 지키면 좋은 순서로 알맞은 것은?

1. `rm -i` → `pwd` → `ls`
2. `ls` → `rm -i` → `pwd`
3. `pwd` → `ls` → `rm -i` → `ls`
4. `rm -i` → `rm -i` → `ls`

**7.** `fruit.txt`에 `apple`, `banana`, `apple`, `cherry`, `banana`, `apple`이 한 줄씩 들어 있다. `grep -c "apple" fruit.txt`의 결과는?

1. `6`
2. `4`
3. `2`
4. `3`

**8.** `grep -v "INFO" log.txt`가 보여 주는 것은?

1. `INFO`가 **들어 있지 않은** 줄
2. `INFO`가 들어 있는 줄
3. `INFO`가 들어 있는 줄의 개수
4. `INFO`가 들어 있는 줄의 줄 번호

**9.** `uniq -c`를 쓰기 전에 `sort`를 먼저 하는 이유는?

1. 글자를 대문자로 바꾸려고
2. 파일을 지우려고
3. `uniq`는 **바로 이웃한** 같은 줄만 합치기 때문에, 같은 줄을 먼저 모아 주려고
4. 줄 번호를 붙이려고

**10.** nano에서 글을 고친 뒤 **저장하고 나오는** 순서로 알맞은 것은?

1. `Ctrl + X` → `Ctrl + O`
2. `Ctrl + O` → `Enter` → `Ctrl + X`
3. `Ctrl + C` → `q`
4. `Esc` → `exit`
